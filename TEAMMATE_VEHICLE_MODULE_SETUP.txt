GreenPool Vehicle Management Module
队友安装与运行指南
====================================

1. 队友取得你的 Branch
----------------------

如果已经 clone repository：

git fetch origin
git switch vehicle-management
git pull origin vehicle-management

如果还没有 clone：

git clone <repository-url>
cd greenpool
git switch vehicle-management


2. 需要安装的软件
-----------------

队友电脑需要：

- PHP 8.2+
- Composer
- Node.js 20+
- Python 3.12 64-bit（建议）
- MySQL/XAMPP，或者使用 SQLite
- Git

检查版本：

php -v
composer --version
node --version
npm --version
py -3.12 --version


3. 安装 Laravel 和前端依赖
--------------------------

在项目目录运行：

composer install
npm install

建立 .env：

Copy-Item .env.example .env
php artisan key:generate


4. 设置数据库
-------------

方案 A：使用 MySQL

先在 phpMyAdmin 或 MySQL Workbench 建立数据库：

greenpool

然后修改 .env：

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=greenpool
DB_USERNAME=root
DB_PASSWORD=

运行：

php artisan migrate
php artisan storage:link

如果需要测试资料，可以运行：

php artisan db:seed


方案 B：使用 SQLite

New-Item database\database.sqlite -ItemType File

.env 使用：

DB_CONNECTION=sqlite

然后运行：

php artisan migrate
php artisan storage:link


5. 安装 OCR
-----------

建立 Python virtual environment：

py -3.12 -m venv .venv

安装 OCR dependencies：

.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r .\ocr\requirements.txt

测试：

.\.venv\Scripts\python.exe -c "import paddleocr; print('OCR ready')"


6. 配置 .env
-----------

每位队友的路径不同，需要使用自己电脑的项目路径：

OCR_PYTHON_BINARY=C:\Users\USERNAME\Desktop\greenpool\.venv\Scripts\python.exe
OCR_TIMEOUT=120
OCR_LOW_CONFIDENCE_THRESHOLD=0.75

LOCAL_VEHICLE_VISION_ENABLED=true
LOCAL_VEHICLE_VISION_NODE=C:\Program Files\nodejs\node.exe
LOCAL_VEHICLE_VISION_MODEL=Xenova/clip-vit-base-patch32
LOCAL_VEHICLE_VISION_TIMEOUT=180

如果不知道 Node.js 路径：

(Get-Command node).Source

把显示的路径放入 LOCAL_VEHICLE_VISION_NODE。

这套功能使用本地模型，不需要 Grok/XAI API Key。


7. 清除 Laravel Cache
---------------------

php artisan optimize:clear


8. 启动系统
-----------

打开第一个 VS Code terminal：

php artisan serve

打开第二个 terminal：

npm run dev

然后进入：

http://127.0.0.1:8000

不需要单独启动 OCR server；Laravel 扫描时会自动调用 Python。


9. 第一次使用注意
------------------

第一次点击以下功能时：

- Validate photo
- Scan & prefill

系统需要下载本地 PaddleOCR 和车辆图片识别模型，因此：

- 需要网络
- 第一次可能需要几分钟
- 不要立即关闭 terminal
- 下载完成后，之后会使用本地缓存，速度会更快


10. 测试 Vehicle Management Module
----------------------------------

运行测试：

php artisan test tests/Feature/Driver/VehicleManagementTest.php

测试正常应该全部通过。

手动测试步骤：

1. 登录 Driver account。
2. 打开 My Vehicles。
3. 点击 Add Vehicle。
4. 上传 front、rear、side 图片。
5. Validate 三张图片。
6. 检查车牌和颜色是否自动填写。
7. 上传 Geran 和 Driving Licence。
8. 两份文件分别点击 Scan & prefill。
9. 点击 Continue 到 Step 3。
10. 检查资料并点击 Add vehicle。
11. 确认系统跳转到 My Vehicles，并显示绿色成功 snackbar。
